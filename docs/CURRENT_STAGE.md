# Текущий этап: Э1 — Комната без медиа

Начато: 2026-08-23 (после Э0, все подзадачи Э0.1–Э0.11 закрыты в предыдущей сессии;
инфраструктурные пункты Э0.8–Э0.11 остаются непроверенными вживую — см. их пометки,
это отдельный известный пробел, не блокирующий разработку Э1).

## Стоп-лист Э1

```
НЕ делать на этом этапе:
- НИКАКОГО LiveKit и WebRTC. Даже "заготовки" и пустых модулей media/
- никакого Yjs и Hocuspocus (это Э3)
- не делать сетку видеоплиток — только текстовый список участников
- не делать демонстрацию экрана
- не делать breakout-комнаты
```

Стоп-лист соблюдён: медиа/WebRTC/Yjs не затронуты, участники — текстовый список.

## Задачи

- [x] Э1.1 WS-эндпоинт `/ws` в том же Fastify-сервере (`@fastify/websocket`).
      Аутентификация по access-токену в query (`?token=&lessonId=`), т.к. браузерный
      WebSocket API не позволяет слать заголовок Authorization.
- [x] Э1.2 Модель комнаты в Redis (`apps/api/src/modules/rooms/presence.ts`, ioredis):
      хэш участников на урок, зачистка через периодический sweep (heartbeat-таймаут
      60с для оборвавшихся без close-фрейма, grace-период 30с на переподключение).
      Presence переживает F5/реконнект клиента в пределах 30с.
- [x] Э1.3 `POST /lessons/:id/join` — проверка прав (админ / учитель этого урока /
      ученик из группы урока), запись сессии в `lesson_participants`. Ученик не из
      группы получает 403 (покрыто тестом).
- [x] Э1.4 Список участников в реальном времени через WS-пуш (`presence`,
      `participant_joined/left`), индикатор соединения (`connected`), «поднял руку».
- [x] Э1.5 Чат: `POST/GET /lessons/:id/chat`, история в Postgres (`chat_messages`,
      пагинация `before`+`limit`), модерация — мягкое удаление учителем
      (`DELETE /lessons/:id/chat/:messageId`).
- [x] Э1.6 Права в уроке: `canDraw`, `canSpeak`, `canShareScreen` в presence-записи,
      `PATCH /lessons/:id/participants/:userId/permissions` — только учитель этого
      урока или админ.
- [x] Э1.7 Жизненный цикл: `scheduled → live` при входе учителя/админа,
      `live → ended` вручную (`POST /lessons/:id/end`) или автоматически через 15 мин
      после ухода последнего участника (таймер в процессе, безопасен к потере при
      рестарте — просто не сработает разово, урок доедут закрыть вручную).
- [x] Э1.8 Реконнект: клиентский экспоненциальный бэкофф (1с→16с) в
      `apps/web/src/features/room/useRoomSocket.ts`; на сервере — grace-период 30с
      без потери состояния участника (права, поднятая рука сохраняются).

## MCP

`.mcp.json` был невалидным JSON (JSONC-комментарии `//`, которые не парсятся как
JSON) — из-за этого ни один сервер не подключался ни в одной сессии. Исправлено:
файл теперь валиден, набор под Э1 — context7, playwright, github (постоянные) +
postgres, redis (ситуативные, ≤5 одновременно по правилу плана). Требуется
перезапуск сессии Claude Code, чтобы серверы подключились; postgres/redis MCP всё
равно не заработают без живого `docker compose up`, github MCP — без `GITHUB_TOKEN`.

## Известные пробелы (нужны от пользователя)

1. **Docker по-прежнему недоступен в этой среде** — как и в Э0, нельзя поднять
   `docker compose up` и прогнать гейт Э1 (200 WS-соединений, проверка утечки).
2. Нужен перезапуск Claude Code для подключения MCP-серверов после починки
   `.mcp.json`.
