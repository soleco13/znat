## Устройство

- Данные владельцев аккаунтов: ИП — оператор.
- Данные учеников в уроках: оператор — учитель или школа, ИП обрабатывает их по поручению (Приложение 1 к соглашению). Так устроены Контур Толк, Zoom и другие сервисы для школ: согласия родителей собирает тот, кто знает ученика.
- Права по соглашению заранее можно передать будущему ООО (п. 9.2 соглашения), данные — тоже (п. 6.6 политики).

## Что заполнить

- `[email для обращений]` — отдельный ящик, например `support@matis-edu.ru` (создать на reg.ru).
- `[дата публикации]` — дата выкладки на сайт.
- Номер в реестре операторов ПДн — после подачи уведомления в Роскомнадзор (pd.rkn.gov.ru, через Госуслуги). Подать до начала обработки; за неподачу с 30.05.2025 штраф для ИП до 300 тыс. ₽ (ст. 13.11 КоАП).
- Хостинг-провайдер сервера: наименование и ИНН (п. 6.3 политики).
- ИНН ООО «Регистратор доменных имён РЕГ.РУ» (п. 6.3 политики) — сверить с договором.
- Срок хранения технических журналов (п. 5 политики) — сверить с настройками логов.

## Что поменять на сайте после одобрения

- Страницы /terms, /privacy, /consent, /consent/lesson, /requisites; ссылки на них в подвале.
- `PersonalDataConsent`: галочка ведёт на текст согласия (/consent или /consent/lesson), ссылка на политику — отдельно.
- Вход в урок (`GuestJoinPage`): в согласие Б подставлять название школы или ФИО учителя из урока.
- Регистрация: рядом с галочкой — «Регистрируясь, вы принимаете Пользовательское соглашение».
