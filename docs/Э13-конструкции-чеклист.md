# Чек-лист: что добавить в редактор материалов (шаблоны + интерактив)

Составлено 2026-09-07 по запросу пользователя. Источник идей — разбор
текущего кода + H5P / QTI 3.0 / Wordwall / Skysmart (ссылки в конце).
Это **список для отбора**, не план работ. Ничего не реализовано.

---

## 0. Что уже есть (базис, от чего считаем)

**Контент-блоки (9):** `rich_text`, `image`, `video`, `audio`, `formula`
(KaTeX), `table`, `callout`, `embed`, `page_break`.

**Типы вопросов (10):** `single_choice`, `multiple_choice`, `true_false`,
`text_input` (exact/normalized/regex + опечатки), `numeric_input`
(допуск absolute/relative/percent + единицы), `open_answer` (рубрика,
ручная проверка), `cloze_dropdown`, `cloze_text`, `matching`, `ordering`.

**Конструкции (10):** 5 каркасов — разбор задачи, блок проверки, словарный
диктант, определение+теорема, параграф с проверкой; 5 готовых блоков —
врезки Определение / Теорема / Пример, выбор из 4, числовой с допуском.

**Вывод:** ядро закрывает «тест + текст». Не закрыто ровно то, что делает
задание предметным: **картинка как поле ответа, работа по тексту,
классификация, таблица-заготовка, рисунок ученика**.

## 1. Цена вопроса (учитывать при отборе)

**Новая конструкция-шаблон = 0 нового кода.** Только запись в
`material-templates.ts` (`MATERIAL_CONSTRUCTS`) + пункт в «/»-меню
(`editor/slash-menu.tsx`) + `triggers` для контекстной подсказки.
Собирается из существующих блоков. Это самая дешёвая часть списка —
раздел 3 целиком реализуется без единого нового типа.

**Новый тип вопроса = 7 точек касания:**
1. `packages/shared/src/materials.ts` — `*InteractionSchema` +
   `*ResponseSchema` + оба дискриминированных union;
2. `stripMaterialAnswerKeys` (там же) — вырезать ключ ответа;
3. `apps/api/src/modules/materials/grading.ts` — `case` в `gradeResponse`;
4. `apps/api/src/modules/materials/validation.ts` — правила валидности;
5. `apps/web/src/features/materials/QuestionPlayer.tsx` — рендер ученику;
6. `QuestionInteractionEditors.tsx` (+ `editor/question-view.tsx`) — редактор;
7. `block-factories.ts` + `editor/slash-menu.tsx` — вставка.

**Ограничения проекта, которые режут часть идей:**
- Проверка только на сервере — ключи не уходят на клиент до сабмита
  (координаты хотспотов, слова-ответы в «выдели в тексте» — тоже ключи).
- Никаких чужих CDN и внешних рантаймов на критическом пути урока.
  GeoGebra/Desmos/PhET как встройка — **нет**; аналог пишем сами или
  раздаём статикой у себя (оффлайн-сборка PhET допустима только как
  self-hosted `embed`, и то решается отдельно).
- Картинки/аудио — только через `MediaAssetPicker` / StorageAdapter.
- **Новых зависимостей почти не нужно:** `@dnd-kit/*` (drag), `katex`,
  `mathlive`, `@excalidraw/excalidraw` уже в `apps/web/package.json`.

**Что даёт shadcn-реестр (проверено через shadcn MCP):** `tabs`,
`collapsible`, `table`, `progress`, `switch` — уже стоят. Не стоят, но
есть в реестре и закрывают пункты списка: `slider` (для `slider` /
`number_line`, тянет `@radix-ui/react-slider`), `accordion` (спойлер
«показать решение», тянет `@radix-ui/react-accordion`), `carousel`
(галерея и колода флеш-карточек, тянет `embla-carousel-react`).
Три новые зависимости — спросить перед установкой.

## 2. Универсальные типы вопросов (работают на всех предметах)

Приоритет — по отношению «польза / цена». `[ ]` — к обсуждению.

### Волна 1 — максимальный охват предметов, без новых зависимостей

- [ ] **`mark_text` — выделить в тексте** (QTI hottext / H5P Mark the
      Words). Ученик кликает слова/фрагменты: найди все глаголы, найди
      ошибки, найди эпитеты, найди аргументы в тексте, найди неверные
      утверждения. Автопроверка частичным баллом.
      *Русский, литература, английский, история, обществознание, биология.*
- [ ] **`categorize` — разложить по корзинам** (drag N карточек в M
      колонок). Одушевлённые/неодушевлённые, металлы/неметаллы,
      факты/мнения, живая/неживая природа, части речи.
      Отличается от `matching` тем, что связь «много к одному».
- [ ] **`table_fill` — таблица с пропусками.** Заготовка таблицы, часть
      ячеек — поля ввода/выпадашки. Трассировка алгоритма, таблица
      измерений в лабораторной, сравнительная таблица, спряжение.
- [ ] **`image_labeling` — подписи на изображении** (QTI graphic gap
      match). Перетащить подписи в зоны картинки: схема клетки, контурная
      карта, части речи в схеме предложения, детали механизма, ноты.
- [ ] **`hotspot` — клик по области изображения** (QTI hotspot / select
      point). «Покажи на карте», «найди ошибку на чертеже», «где на
      графике максимум». Одна или несколько зон.
- [ ] **`matrix_choice` — матрица утверждений.** Строки-утверждения ×
      колонки (верно/неверно или 3–4 категории). Один блок вместо десяти
      `true_false`.
- [ ] **`ordering` с картинками + горизонтальная лента.** Расширение
      существующего типа: элементы = изображения, режим «таймлайн».
      Хронология, стадии митоза, шаги доказательства.
- [ ] **`drag_words` — перетащить слова в пропуски.** Третий UI поверх
      уже существующей модели `cloze_*` (не новый ключ ответа, а новый
      способ ввода). Дёшево, заметно приятнее для младших классов.
- [ ] **`canvas_answer` — задание «начерти / нарисуй»** на Excalidraw
      (движок уже в стеке, работает на доске урока). Ответ = картинка,
      проверка ручная через `GradingQueue` — как `open_answer`.
      *Геометрия, физика (схемы), география (профиль), ИЗО, биология.*

### Волна 2 — точечно, но сильно

- [ ] **`file_upload` — фото решения / лабораторной.** Ручная проверка,
      лимит размера, путь через StorageAdapter.
- [ ] **`audio_response` — запись голоса.** Чтение вслух, английское
      произношение, стихотворение наизусть. Ручная проверка.
      MediaRecorder + хранилище; без распознавания речи.
- [ ] **`slider` / `number_line` — ответ на шкале.** Точка на числовой
      прямой, оценка «на глаз», координата. Проверка = попадание в диапазон.
- [ ] **`image_choice` — варианты ответа картинками.** Портреты,
      репродукции, схемы, знаки.
- [ ] **`connect_lines` — соединить линиями.** Тот же ключ ответа, что и
      `matching`, но UI линиями по картинке/двум колонкам.
- [ ] **`crossword` / `wordsearch` / `anagram`** — словарная тройка.
      Кроссворд ощутимо дороже остальных (сетка + генератор).
- [ ] **`multi_step` — многошаговое задание.** Шаг 2 открывается после
      шага 1, каждый шаг оценивается. Задачи «в три действия».

### Волна 3 — предметные, узкие, дорогие

- [ ] **`chem_equation` — уравнивание реакции.** Поля коэффициентов +
      проверка баланса атомов (парсер формул на сервере, ~200 строк).
- [ ] **`function_plot` — построить/узнать график.** Свой плоттер на
      canvas (внешние GeoGebra/Desmos запрещены правилом §1.2 ТЗ).
- [ ] **`code_answer` — программа с проверкой.** Запуск кода ученика
      требует песочницы — отдельный риск и отдельное решение. Дешёвая
      замена сейчас: `text_input` «что выведет программа» + `cloze_text`
      по коду моноширинным шрифтом.
- [ ] **`math_expression` — ответ формулой** (mathlive уже есть): проверка
      на эквивалентность выражений, а не строкой.

## 3. Конструкции-шаблоны по предметам (0 нового кода — можно делать сразу)

Собираются из **уже существующих** блоков. Пометка *(в1)* — заиграет
сильнее после волны 1, но базовая версия работает уже сейчас.

### Русский язык
- [ ] Вставь пропущенную букву (`cloze_text`, 8–10 слов)
- [ ] Расставь знаки препинания (`cloze_dropdown`: `,` / `—` / `:` / нет)
- [ ] Орфоэпическая разминка «ударение» (`single_choice` × 5)
- [ ] Разбор слова по составу (схема + `text_input` на морфемы) *(в1: image_labeling)*
- [ ] Синтаксический разбор предложения *(в1: mark_text)*
- [ ] Найди и исправь ошибку в предложении (`text_input`)
- [ ] Работа с текстом: текст + 5 вопросов формата ОГЭ/ЕГЭ
- [ ] Части речи: разложи слова по группам *(в1: categorize)*

### Литература
- [ ] Цитата + вопрос на анализ (`open_answer` с рубрикой)
- [ ] «Кто автор строк» (`matching`)
- [ ] Герой — произведение — характеристика (`matching`)
- [ ] Хронология событий сюжета (`ordering`)
- [ ] Средства выразительности: найди в тексте *(в1: mark_text)*
- [ ] Сочинение-миниатюра (`open_answer` + рубрика с критериями)

### Английский
- [ ] Лексический набор: слово — перевод (`matching` × 10)
- [ ] Listening: аудио + 4 вопроса на понимание
- [ ] Грамматический gap-fill: времена (`cloze_dropdown`)
- [ ] Порядок слов в предложении (`ordering`)
- [ ] Диалог с пропусками реплик (`cloze_dropdown`)
- [ ] Speaking: прочитай вслух *(в2: audio_response)*
- [ ] Word formation (`text_input` с нормализацией)

### Математика / алгебра / геометрия
- [ ] Разбор задачи *(есть)*
- [ ] Реши уравнение (`numeric_input` + допуск)
- [ ] Формула → подстановка → ответ (три блока)
- [ ] Расставь шаги доказательства по порядку (`ordering`)
- [ ] Задача с чертежом (`image` + `numeric_input`)
- [ ] Найди ошибку в решении (решение + `single_choice` «на каком шаге»)
- [ ] Устный счёт: 10 быстрых числовых
- [ ] Построй фигуру *(в1: canvas_answer)*

### Физика
- [ ] Задача с единицами измерения (`numeric_input`, `unitRequired`)
- [ ] Лабораторная: таблица измерений + вывод *(в1: table_fill)*
- [ ] Чтение графика (`image` + вопросы) *(в1: hotspot)*
- [ ] Формула: что из чего выражается (`matching`)
- [ ] Качественный вопрос «почему» (`open_answer` + рубрика)
- [ ] Схема электрической цепи *(в1: image_labeling / canvas_answer)*

### Химия
- [ ] Классификация веществ *(в1: categorize)*
- [ ] Цепочка превращений (`ordering` / `cloze_text`)
- [ ] Расчётная задача по уравнению (`numeric_input` с допуском)
- [ ] Уравняй реакцию (сейчас — `cloze_text` коэффициентами; *в3: chem_equation*)
- [ ] Таблица Менделеева: свойства элемента (`matching`)
- [ ] Техника безопасности: что не так на картинке *(в1: hotspot)*

### Биология
- [ ] Подпиши схему (клетка, цветок, скелет) *(в1: image_labeling)*
- [ ] Классификация организмов *(в1: categorize)*
- [ ] Последовательность процесса (`ordering`)
- [ ] Сравнительная таблица *(в1: table_fill)*
- [ ] Определи по фотографии *(в2: image_choice)*

### География
- [ ] Контурная карта: покажи объект *(в1: hotspot / image_labeling)*
- [ ] Страна — столица — материк (`matching`)
- [ ] Координаты точки (два `numeric_input` с допуском)
- [ ] Чтение климатограммы (`image` + вопросы)
- [ ] Природные зоны *(в1: categorize)*

### История и обществознание
- [ ] Лента времени: расставь события (`ordering`) *(в1: лента с картинками)*
- [ ] Дата — событие (`matching`)
- [ ] Работа с историческим источником: фрагмент + 4 вопроса
- [ ] Узнай личность по портрету *(в2: image_choice)*
- [ ] Карта сражения / территории *(в1: hotspot)*
- [ ] Правовой кейс + вопросы (`open_answer` + рубрика)
- [ ] Признаки понятия: отбери верные (`multiple_choice`)

### Информатика
- [ ] Что выведет программа (`text_input`)
- [ ] Код с пропусками (`cloze_text`, моноширинный)
- [ ] Трассировка алгоритма по шагам *(в1: table_fill)*
- [ ] Порядок блоков алгоритма (`ordering`)
- [ ] Перевод систем счисления (`numeric_input`)
- [ ] Таблица истинности *(в1: table_fill / matrix_choice)*

### Музыка, ИЗО, МХК, ОБЖ
- [ ] Аудиофрагмент + вопрос об инструменте/эпохе (`audio` + `single_choice`)
- [ ] Репродукция + анализ (`open_answer`)
- [ ] Узнай стиль/эпоху *(в2: image_choice)*
- [ ] Алгоритм действий в ЧС (`ordering`)

## 4. Неоценочные интерактивные блоки (объяснять, а не проверять)

Все дёшевы — это контент-блоки, не вопросы: нет ключа ответа, не трогают
grading и `stripMaterialAnswerKeys`.

- [ ] **Спойлер / «показать решение»** — Collapsible уже в UI-ките
- [ ] **Пошаговое раскрытие (степпер)** — шаги решения по кнопке «дальше»
- [ ] **Вкладки** — «способ 1 / способ 2», «теория / пример»
- [ ] **Флип-карточки** и колода для самопроверки (термин ↔ определение)
- [ ] **Точки на картинке с пояснением** (hotspot без оценки) — анатомия,
      карта, схема прибора
- [ ] **Сравнение «до/после»** — шторка на двух изображениях
- [ ] **Лента времени** как контент
- [ ] **Интерактивная таблица Менделеева** — свои данные, оффлайн, без CDN
- [ ] **Вывод формулы по шагам** (KaTeX + степпер)
- [ ] **Галерея изображений / слайдер**
- [ ] **Оглавление листа** *(уже висит в «Осталось по Э13»)*

## 5. Механики поверх заданий (не типы вопросов)

- [ ] **Банк вопросов:** «показать 5 случайных из 20»
- [ ] **Параметризованные задачи:** числа в условии генерируются по
      шаблону — у каждого ученика свой вариант. Самое сильное средство
      против списывания, но требует движка подстановок и проверки.
- [ ] **Ветвление:** ошибся → дополнительное объяснение и лёгкий вопрос
- [ ] **Режим тренажёра:** повтор до правильного, мгновенная обратная связь
      (в `materialSettings` уже есть `showFeedback` и попытки — надстройка)
- [ ] **Таймер на блок/материал**
- [ ] **Разноуровневость:** пометка вопроса «база / профиль» и фильтр
- [ ] **Импорт вопросов** из CSV / таблицы Word (импорт документов уже есть)
- [ ] **Стартовая библиотека** готовых материалов по предметам

---

## 6. Предлагаемая очерёдность

1. **Раздел 3 целиком** — ~50 конструкций, кода не требуют, дают охват
   всех школьных предметов сразу. Максимальный эффект на единицу работы.
2. **Волна 1 раздела 2** — 9 типов; после них конструкции из раздела 3
   переписываются на «настоящий» интерактив.
3. **Раздел 4** — неоценочные блоки, дешёвые и заметные.
4. **Волна 2**, затем механики раздела 5.
5. **Волна 3** — только то, что реально попросят преподаватели.
