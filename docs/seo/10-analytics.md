# Аналитика

**Статус (25.11.2026): Umami на своём сервере работает, счётчик на всех страницах сайта.** Ниже — исходный план с Метрикой (не выбрана).

## Umami

- Панель: https://stats.matis-edu.ru (вход владельца). Сервис `umami` в docker-compose.prod.yml, база `umami` в нашем Postgres.
- Наружу на основном домене только `/u/script.js` и `/u/api/send`; счётчик срабатывает только на matis-edu.ru, без cookie, IP не хранится. Ботов (в том числе headless Chrome) Umami отбрасывает сам.
- События: «Начать бесплатно», «Войти», «Демонстрация», «Подключить тариф» (с тарифом), «Telegram» — у каждого `place` (где на странице); «Статья дочитана».
- Проверено: запрос из обычного браузера записался; тестовая запись удалена.

## Исходный план (Метрика)

**Статус: не выбрана.** Счётчик Яндекс Метрики передаёт данные посетителей Яндексу: до установки нужно поправить политику обработки персональных данных и показать уведомление о cookie.

## Предложение

- Метрика только на страницах сайта (`/`, `/pricing`, `/contacts`), **не** в приложении и не в уроках. Вебвизор выключен.
- Внутренние события приложения (регистрация, первый урок, оплата) считать на своём сервере и передавать в Метрику только факт цели через офлайн-конверсии — без почты, имён, токенов и содержимого уроков.

2. Номер счётчика (metrika.yandex.ru → «Добавить счётчик», адрес matis-edu.ru).
3. Согласовать правку политики и текст уведомления о cookie — подготовлю.
