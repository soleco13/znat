# Аналитика

**Статус: заблокировано решением владельца.** Счётчик Яндекс Метрики передаёт данные посетителей Яндексу: до установки нужно поправить политику обработки персональных данных и показать уведомление о cookie.

## Предложение

- Метрика только на страницах сайта (`/`, `/pricing`, `/contacts`), **не** в приложении и не в уроках. Вебвизор выключен.
- Внутренние события приложения (регистрация, первый урок, оплата) считать на своём сервере и передавать в Метрику только факт цели через офлайн-конверсии — без почты, имён, токенов и содержимого уроков.

## Цели

| Цель | Где | Как |
|---|---|---|
| Переход на тарифы | сайт | просмотр `/pricing` |
| Клик «Начать бесплатно» / «Войти» | сайт | JS-цель |
| Запрос демонстрации | сайт | JS-цель |
| Регистрация подтверждена | сервер | офлайн-конверсия |
| Первый урок проведён | сервер | офлайн-конверсия |
| Переход к оплате / оплата | сервер | офлайн-конверсия |

## Что нужно от владельца

1. Решение: ставим Метрику или нет.
2. Номер счётчика (metrika.yandex.ru → «Добавить счётчик», адрес matis-edu.ru).
3. Согласовать правку политики и текст уведомления о cookie — подготовлю.
