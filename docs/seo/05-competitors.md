# Конкуренты (первичный список)

Собрано по выдаче 25.11.2026. Цены и возможности конкурентов — со слов источников, перед публикацией сравнения проверять на их сайтах.

| Кто | Тип | Что предлагает по источникам | Чем отличается от Матиса |
|---|---|---|---|
| ProgressMe | платформа для репетиторов (языки) | виртуальный класс, видеосвязь, доска, база уроков, тренажёр | упор на готовые курсы; Матис — урок по ссылке без регистрации ученика |
| VK Tutoria | бесплатный сервис VK | календарь, доска, VK Звонки, группы до 100 | экосистема VK; Матис — отдельный сервис без аккаунта у ученика |
| Сферум | платформа для школ (госсектор) | связь и классы для школ | для общеобразовательных школ, не для частных репетиторов |
| Контур.Толк / Контур.Класс | ВКС и обучение для бизнеса | видеовстречи, онлайн-доски, курсы | B2B-корпоративный; у Матиса урок, доска и слайды в одном окне |
| Zoom | универсальная ВКС | видеосвязь, доска | нет урочных сценариев; для ученика — установка/аккаунт |
| Preply | маркетплейс репетиторов | своя видеоплатформа с доской | площадка-посредник с комиссией, не инструмент для своих учеников |

## Что сделать в волне 2

Для каждого: title/description, H1, структура посадочных, какие запросы забирают (по Вордстату и выдаче Яндекса), чего у них нет. Источники обзоров, где можно появиться: timeweb.com/ru/community, mel.fm, startpack.ru — см. будущий 09-external-promotion.md.
