# Карта спроса

**Статус: заблокировано внешним доступом.** Частотность не выдумываем: нужны данные Яндекс Вордстата (вход в аккаунт Яндекса) или выгрузка от владельца.

## Что нужно от владельца

Выгрузка из wordstat.yandex.ru (регион — Россия, за 12 месяцев) по каждой фразе из `04-semantic-core.csv` в трёх видах: без операторов, `"фраза"` и `"!точная !фраза"`, плюс вкладка «Динамика» для сезонности. Либо доступ к браузерной сессии с входом в Яндекс — тогда соберу сам.

## Гипотезы кластеров (до проверки спросом)

| Кластер | Интент | Целевая страница (план) |
|---|---|---|
| Платформа для репетитора | коммерческий | `/repetitoram` |
| Сервис / программа для онлайн-уроков | коммерческий | главная |
| Онлайн-доска для уроков | смешанный | `/doska` |
| Платформа для онлайн-школы | коммерческий (B2B) | `/shkolam` — после открытия школьных тарифов |
| Виртуальный / онлайн-класс | смешанный | главная или `/repetitoram` |
| Аналог Zoom для обучения | сравнительный | `/sravnenie` |
| Как вести онлайн-уроки | информационный | статьи |

Кластеры, у которых в Вордстате окажется мало спроса или чужой интент, отбрасываем.
