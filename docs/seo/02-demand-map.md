## Выводы

1. **Главная должна отвечать на «платформа для репетиторов».** Это самый большой коммерческий запрос, а продукт сейчас продаётся только репетиторам. Отдельная страница «для репетиторов» повторила бы главную — дубль. Нужно, чтобы title, H1 и первый абзац главной говорили этими словами.
2. **Онлайн-доска — вторая точка входа.** 4+ тыс. запросов в месяц; конкуренты в запросах — sboard, edloop (едлуп), holst, miro, классапер: отдельные доски без видеосвязи. Честное отличие Матиса — доска, видео и слайды в одном окне урока. Отдельная страница `/doska` оправдана: свой интент, свой контент.
3. **«Бесплатно» — в каждом кластере** (466, 441, 291, 204, 135…). У Матиса есть бесплатный «Старт» без срока — это надо говорить в title и описаниях.
4. **Предметы** (математика, английский, русский, подготовка к школе, ЕГЭ) — десятки–сотни запросов на каждый. Отдельные страницы под предметы — тонкие дубли; лучше абзац или пример на `/doska` и в статьях.
5. **Страницу сравнения с Zoom не делаем** — спроса нет. Сравнение с досками-конкурентами — возможно позже, в статье «лучшие онлайн-доски для репетитора» (доски для репетиторов лучшие онлайн — 112, топ онлайн досок — 13).
6. **Нецелевое** — «платформа для поиска репетитора» (318) и «для поиска учеников» (84): это маркетплейсы, Матис учеников не ищет.
