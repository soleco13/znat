### `/doska` — структура (черновик)

- H1 «Онлайн-доска для уроков с учеником»; первый абзац — определение: что это и чем отличается (видео, доска и слайды в одном окне, ученик входит по ссылке без регистрации).
- H2 «Что можно на доске» — только то, что реально есть в уроке (сверить с кодом перед текстом).
- H2 «Как ученик попадает на доску».
- H2 «Для каких предметов» — математика, английский, русский: короткие примеры.
- H2 «Сколько стоит» — «Старт» бесплатно, «Репетитор» 790 ₽; ссылка на `/pricing`.
- H2 «Частые вопросы» — 4–6 прямых ответов.
