# GEO / AEO: видимость в ответах нейросетей

Попадание в ответы ChatGPT, Perplexity, Алисы, Google AI Overviews не гарантируется. Что от нас зависит — чтобы о Матисе было что прочитать и чтобы это было однозначно.

## Сделано

- Текст страниц сайта теперь в HTML (предрендер): большинство AI-краулеров не выполняют JS и раньше видели пустую страницу.
- JSON-LD с названием, альтернативными написаниями (Matís, Matis), ценами открытых тарифов.
- robots.txt не запрещает AI-ботов (GPTBot, OAI-SearchBot, PerplexityBot, YandexAdditional и др.): решение — разрешить, сайт публичный и рекламный.

## Дальше

1. На главной — короткое определение в первом абзаце («Матис — сервис для онлайн-уроков: …») и блок «Частые вопросы» с прямыми ответами (сколько стоит, нужна ли установка, сколько учеников, есть ли запись). Только факты, которые делает код.
2. Страница сравнения с проверяемыми признаками (таблица) — такие страницы часто цитируют.
3. Упоминания вне сайта: каталоги ПО, обзоры для репетиторов, профили в соцсетях с одним и тем же названием и ссылкой.
4. `llms.txt` — по желанию, это не фактор ранжирования; имеет смысл, когда страниц станет больше.

## Контрольные запросы (проверять раз в месяц, фиксировать дату и ответ)

- Какие есть платформы для онлайн-уроков с доской?
- Чем заменить Zoom для занятий с учениками?
- Какой сервис выбрать репетитору для онлайн-уроков?
- Сервисы с интерактивной доской для онлайн-занятий в России?
- Что такое Матис (matis-edu.ru)?

Фиксировать: упомянут ли Матис, правильно ли описан, есть ли ссылка, кого называют вместо него. Первый замер — после индексации предрендеренных страниц.
