# SEO-аудит matis-edu.ru — волна 1

Дата: 25.11.2026. Проверено: репозиторий (`landing/`, `apps/web/`, `Caddyfile`) и живой сайт — запросами `curl` (это тот HTML, который получает робот до выполнения JS) и в headless Chrome.

## Как устроен сайт

| Часть | Адреса | Как отдаётся |
|---|---|---|
| Сайт (лендинг) | `/`, `/pricing`, `/contacts` | отдельная сборка `landing/` (Vite multi-page, React), Caddy отдаёт файлы из `landing/dist` |
| Приложение | `/login`, `/register`, `/lessons`, `/terms`, `/privacy`, уроки по ссылке `/<код>` и любые другие адреса | SPA `apps/web`, на любой адрес — один и тот же `index.html` |
| API | `/api/*` | JSON |

Хорошо сделано до аудита: свои адреса без `#`, `https` и редирект `http → https` (308), `www → без www` (301), `/pricing/ → /pricing` (301), уникальные title и description на трёх страницах, canonical, Open Graph, robots.txt и sitemap.xml из сборки, сжатие brotli, долгий кеш ассетов.

## После исправлений (локальная сборка)

HTML главной — 45 КБ с текстом: H1 «Онлайн-урок в одной вкладке», 6 H2, ссылки в шапке и подвале; «Тарифы» и «Контакты» — по 13–15 КБ. В headless Chrome (1440 и 390 px) все три страницы открываются без ошибок консоли, вид не изменился.
